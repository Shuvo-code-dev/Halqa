## &nbsp; ◌ &nbsp; The Problem

You opened 47 tabs. You have 12 unfinished Udemy courses. You don't know whether to learn Vue or React. Someone on Reddit said Node.js is dead.

**You are not the problem. The information landscape is.**

Halqa exists to fix that.

<br />

## &nbsp; ✦ &nbsp; What is Halqa?

**Halqa** `(حلقة)` — Arabic for *circle*. A gathering. A focused group with a shared purpose.

We are that circle for developers who are tired of the noise.

> One curated path. Free resources only. Zero distractions.  
> From your first `console.log` to your first pull request — we stay with you.

<br />

## &nbsp; 🤝 &nbsp; Join the Circle

Halqa is **nothing** without its contributors. Every roadmap addition, resource suggestion, or typo fix makes it better for thousands of developers who come after you.

```bash
# Step into the circle
git clone https://github.com/Shuvo-code-dev/Halqa.git
cd Halqa

# Create your branch
git checkout -b feat/your-contribution

# Make your mark
git commit -m "feat: add [resource/fix/roadmap] for [topic]"

# Send it
git push origin feat/your-contribution
# → Then open a Pull Request on GitHub
```

Before contributing, read **[CONTRIBUTING.md](CONTRIBUTING.md)** — it's a 2-minute read, we respect your time.
