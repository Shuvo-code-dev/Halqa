# Bulz | The Global Developer Ecosystem

**Bulz** (حلقة - Circle of Learning) is a high-density, world-class educational platform designed to turn noise into mastery. It provides a premium, bootcamp-style learning experience through structured roadmaps and an elite UI repository.

## 🚀 Key Features

### 1. Roadmap Universe
- **16+ Specialized Routes**: From Frontend and Mobile to Linux Internals and CS Fundamentals.
- **Deep Educational Content**: Every roadmap is a full guide with "The Why", "Core Topics", and "Actionable How-To's".
- **Personalized Progress**: Built-in tracking system (`localStorage`) to mark stages as complete.

### 2. Code Lab (Elite UI Registry)
- **High-Fidelity Components**: 20+ React + CSS blocks featuring dynamic animations (GSAP, Framer Motion) and Physics engines.
- **Visual FX Engine**: Includes "Showstopper" components like the **Physics Ballpit** and **Liquid Chrome** (Three.js shaders).
- **Personal Workspace**: Bookmark system to save and organize your favorite snippets.
- **One-Click Integration**: Working copy-paste feedback and "Edit on Playground" links.

### 3. Global Intelligence (i18n)
- **Multilingual Support**: Fully localized in **English** and **Bengali**, with architecture ready for 50+ languages.
- **Zero-Reload Switching**: Instant UI transformation via a global language context.

## 🛠️ Technology Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Vanilla CSS (High-Performance Foundations)
- **Animation**: GSAP, Framer Motion, Three.js
- **State**: React Context (Language, User Space)
